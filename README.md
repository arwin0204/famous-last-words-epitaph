A tiny deterministic program that writes one funny epitaph — a single line of famous last words, carved-in-stone style — to `entry.txt` for the [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406?utm_source=github&utm_medium=readme&utm_campaign=u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty on make.fun.

## Run it

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/tmp/entry.txt` if the variable is not set).
